# Pharmacy Substitution Safety Prototype

A rule-based prescription substitution decision checklist and safety dashboard.

## Overview

This application serves as a prototype for pharmacists and healthcare professionals to safely review and manage prescription substitutions. It includes rule-based decision checklists, safety warnings (such as allergy conflicts or stock shortages), and management tools for follow-ups and audits.

## Features

- **Prescription Review Dashboard**: A comprehensive view of prescriptions requiring substitution or review.
- **Rule-Based Decision Checklist**: Safety checks ensuring patient constraints and allergies are respected.
- **Audit Logs**: Track override actions and decisions made by pharmacy staff.
- **Follow-up Management**: A queue system for tasks requiring external communication (e.g., contacting prescribers).

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
